# 과제 05 — 작업 계획

## 시작 프로젝트
SKT-ALEPH-03의 짤·카드 스튜디오를 복사한 코드.

## 개선 기능
저장된 사용자 템플릿의 이름 검색 기능.

## 완료 조건
docs/task05-tests.md의 고정 검사 10개를 모두 통과한다.
기존 이미지 편집, 템플릿 관리, JSON 백업·복원 기능을 유지한다.

## 공통 사용 상한
- AI A: 작업 시간 최대 30분, 작업 요청 최대 8회.
- AI B: 작업 시간 최대 30분, 작업 요청 최대 8회.
- 작업 요청 메시지 전송을 1회로 센다.
- 재생성 요청도 1회 추가한다.
- 수업에서 별도 호출 수 측정 기준을 지정하면 그 기준을 따른다.

## 시간 측정 기준
각 AI의 첫 구현 요청을 보낸 시각부터
해당 AI 작업을 중단하거나 완료한 시각까지 측정한다.

## A 중단 시점
첫 구현을 반영하고 고정 검사 10개를 한 번 실행한 뒤 인수인계한다.
시간이나 요청 상한에 먼저 도달하면 그때 중단한다.

## 최초 작업 요청
기존 짤·카드 스튜디오에 템플릿 이름 검색 기능을 추가해주세요.
검색 규칙과 완료 기준은 docs/task05-tests.md를 따르세요.
기존 저장 데이터와 이미지 편집, 템플릿 관리,
JSON 백업·복원 기능은 유지하세요.
고정 검사와 기대 결과를 변경하지 마세요.

## 인수인계 원칙
B는 A와 다른 서비스 또는 다른 모델을 사용한다.
B에게는 작업 저장소와 인수인계 문서만 전달한다.
A와 나눈 대화 전문은 전달하지 않는다.
