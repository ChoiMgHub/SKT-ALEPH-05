- A 서비스/모델이 문서에 없어 계획의 서로 다른 서비스/모델 사용 조건은 확인 불가다. 이전 대화 요청 없이 문서 누락으로 기록한다.

## 학생의 최종 확인
- PNG·JPEG 배경 업로드와 PNG 다운로드를 직접 확인했다. 미리보기에 이미지가 표시되고, 저장된 PNG 파일을 열어 이미지와 문구가 정상적으로 저장된 것을 확인했다.
- 결과물 URL과 소스 커밋 URL을 비로그인 시크릿 탭에서 열어 정상 접근을 확인했다.
- A와 B는 서로 다른 서비스 또는 모델을 사용했다. 비교표는 A/B 표기를 유지한다.
- 위 B 검토 당시의 미확인·미커밋 기록은 당시 상태를 보존한 것이다. 이후 B 종료 커밋과 검사 증거를 업로드했으며, 다운로드·업로드는 학생 수동 확인을 마쳤다.
- B 실제 시간은 보존된 측정 기록이 없어 미기록으로 유지한다. 이를 임의의 시간으로 대체하거나 시간 제한 준수를 확인한 것으로 기록하지 않는다.
