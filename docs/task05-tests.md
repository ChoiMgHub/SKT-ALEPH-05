# 과제 05 — 템플릿 이름 검색 고정 검사

## 개선 목표
과제 03의 사용자 템플릿 목록에 이름 검색 기능을 추가한다.
기존 템플릿 데이터와 저장·불러오기·수정·삭제 기능은 유지한다.

## 검색 규칙
- 템플릿 이름에 검색어가 포함되어 있으면 표시한다.
- 카드 본문 문구는 검색하지 않는다.
- 검색창에 입력하면 목록에 바로 반영한다.
- 검색어 앞뒤의 공백은 제거한다.
- 영문 대소문자를 구분하지 않는다.
- 검색어가 비어 있거나 공백뿐이면 전체 목록을 표시한다.
- 결과가 없으면 "검색 결과가 없습니다."를 표시한다.
- 검색 초기화 버튼을 누르면 입력창을 비우고 전체 목록을 표시한다.
- 검색은 저장된 템플릿 데이터를 변경하지 않는다.

## 검사 준비
각 검사는 다음 기본 템플릿 세 개만 저장된 상태에서 시작한다.
검색창은 비워둔다.
검사 안에 여러 행동이 적혀 있으면 순서대로 진행한다.

1. 보안 장애 긴급 알림 (1:1)
2. 인프라 엔지니어의 명언 (4:5)
3. 데일리 커밋 다짐 (9:16)

## 고정 검사 10개

| ID | 입력·행동 | 기대 결과 |
|---|---|---|
| T05-01 | 검색어를 비워둔다. | 기본 템플릿 세 개가 모두 표시된다. |
| T05-02 | 보안을 입력한다. | 보안 장애 긴급 알림 (1:1) 한 개만 표시된다. |
| T05-03 | 명언을 입력한다. | 인프라 엔지니어의 명언 (4:5) 한 개만 표시된다. |
| T05-04 | 다짐을 입력한다. | 데일리 커밋 다짐 (9:16) 한 개만 표시된다. |
| T05-05 | 보안 장애 긴급 알림 (1:1)을 입력한다. | 해당 템플릿 한 개만 표시된다. |
| T05-06 | 보안 앞뒤에 공백을 두 칸씩 넣어 입력한다. | 보안 장애 긴급 알림 (1:1) 한 개만 표시된다. |
| T05-07 | 공백만 세 칸 입력한다. | 기본 템플릿 세 개가 모두 표시된다. |
| T05-08 | 없는템플릿xyz를 입력한다. | 템플릿 항목은 0개이고, 검색 결과가 없습니다.라는 안내가 표시된다. |
| T05-09 | 보안을 입력한 다음 검색 초기화 버튼을 누른다. | 입력창이 비워지고 기본 템플릿 세 개가 모두 표시된다. |
| T05-10 | 보안을 검색하고 해당 템플릿의 불러오기를 누른다. | 보안 템플릿의 원래 문구와 1:1 비율이 적용된다. 저장된 템플릿 데이터는 변경되지 않고 세 개가 유지된다. |

## 기록 원칙
- 구현 시작 전에 위 검사를 고정한다.
- A와 B 모두 같은 검사를 사용한다.
- 통과시키기 위해 검사를 삭제하거나 기대 결과를 바꾸지 않는다.
- 실행하지 않은 검사를 PASS로 기록하지 않는다.
- 각 실행 회차의 실제 결과는 별도의 작업 기록에 남긴다.
